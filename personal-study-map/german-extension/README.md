# Расширение «Мой немецкий словарь»

1. Открой в Chrome `chrome://extensions`.
2. Включи «Режим разработчика» (Developer mode).
3. Нажми «Загрузить распакованное расширение» (Load unpacked).
4. Выбери папку `german-extension` вместе со всеми файлами.
5. Выдели немецкое слово на странице, нажми правой кнопкой мыши и выбери «Добавить … в немецкий словарь».
6. Посмотри результат в разделе «Немецкий» на сайте карты навыков.

Работает с выделенным текстом на веб-страницах и во встроенном PDF-просмотрщике, если Chrome передаёт выделение в контекстное меню. На внутренних страницах Chrome функция недоступна.

Сейчас перевод вводится вручную на сайте. Каждый вызов добавляет новую запись (в том числе для повторно выбранного слова).
