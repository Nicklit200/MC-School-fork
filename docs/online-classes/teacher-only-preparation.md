# Preparing a lesson before assigning a pupil

With the modern classroom enabled, a teacher opens every existing owned lesson
through the normal Start online class action, including an unassigned trial.
It materializes the original event and opens the regular classroom and board.
The separate development-only test-class endpoint is not used or enabled.

A room without a pupil or group is accessible only to its owning teacher.
Pupils, parents and other teachers cannot read it, request admission or receive
connection credentials. Its shared PDF, teacher answers, notes and completed
archive remain associated with the original lesson event.

After assigning a pupil or group, the teacher opens the lesson again through
Start online class. The first assignment promotes the existing nonterminal
teacher-only room under its row lock, preserving its ID and prepared ink.
Changing an already assigned audience retains the existing retire-and-replace
behavior. Ending a lesson stays final; assignment does not reopen it.

Migration V97 allows neither audience column to be set, while still rejecting
both columns being set together. No test-class flag or student access rule is
relaxed. The legacy board route and stored operations remain available; it is
the fallback only when the modern classroom deployment switch is disabled.
