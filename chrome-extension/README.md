# Mindcrafti Soniox Reminder

Small Chrome extension for teachers. It runs only on `meet.google.com` and shows a large Mindcrafti reminder after Google Meet displays the post-call screen.

## Install locally in Chrome

1. Download or clone this repository branch.
2. Open `chrome://extensions`.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the `chrome-extension` folder.

After installation, start and leave a Google Meet call. When the Meet leave screen appears, the extension displays **Останови Soniox** directly over the Meet page.

No student data is read or stored by the extension. It only inspects the visible Google Meet page to detect the leave screen.
